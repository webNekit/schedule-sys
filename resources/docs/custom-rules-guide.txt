==============================================================================
        АВТОРСКИЕ ПРАВИЛА ГЕНЕРАЦИИ РАСПИСАНИЯ — ИНСТРУКЦИЯ
==============================================================================

Этот документ объясняет, как создавать собственные правила расписания:
что означает каждое поле формы, что нажимать и зачем.

Раздел в системе:  Админ  ->  Авторские правила  (значок головоломки).
Доступ:            нужно право admin.access.


------------------------------------------------------------------------------
1. ЧТО ТАКОЕ АВТОРСКИЕ ПРАВИЛА
------------------------------------------------------------------------------

Это правила, которые вы описываете сами, в дополнение к встроенным
«Правилам генерации». Они НЕ заменяют встроенные, а складываются с ними.

Каждое правило проверяет расписание и помечает нарушения. Жёсткие правила
типов «Запрет» и «Привязка» вдобавок учитываются прямо при генерации —
генератор старается их не нарушать.

Три типа правил:
  * Запрет   — «такого быть не должно» (запрещает пары по условию).
  * Привязка — «если это такая пара, то она обязана быть такой-то».
  * Лимит    — «считать пары по ключу и сверять с числом» (максимум/минимум).


------------------------------------------------------------------------------
2. СПИСОК ПРАВИЛ (главный экран)
------------------------------------------------------------------------------

На главном экране — таблица всех правил со столбцами:
  Название, Тип, Уровень, Строгость, Вкл., Действия.

  * Переключатель «Вкл.»  — включает/выключает правило (зелёный = включено).
  * Кнопка «Изменить»     — открывает правило в конструкторе.
  * Кнопка «Удалить»      — удаляет правило (с подтверждением).
  * Кнопка «+ Новое правило» (вверху справа) — создать правило с нуля.


------------------------------------------------------------------------------
3. СОЗДАНИЕ ПРАВИЛА — ПОШАГОВО
------------------------------------------------------------------------------

Нажмите «+ Новое правило». Откроется форма. Заполняйте сверху вниз.

ШАГ 1. НАЗВАНИЕ И ОПИСАНИЕ
  * Название  — понятное имя, например «Нет пар в субботу». Обязательно.
  * Описание  — необязательное пояснение (выводится в подсказке конфликта).

ШАГ 2. УРОВЕНЬ (кого касается правило)
  * Глобально  — весь колледж.
  * По курсу   — только выбранный курс (1–4). Появится выбор курса.
  * По группе  — только выбранная группа. Появится выбор группы по названию.
  Поле «Применимость» рядом показывает/выбирает курс или группу.

ШАГ 3. СТРОГОСТЬ
  * Предупреждение — мягко: пару поставят, но нарушение подсветится жёлтым.
  * Ошибка         — жёстко: нарушение критично (красным). Для типов
                     «Запрет» и «Привязка» жёсткое правило вдобавок
                     УЧИТЫВАЕТСЯ ПРИ ГЕНЕРАЦИИ — генератор не поставит
                     такую пару.

ШАГ 4. ВКЛЮЧЕНО
  Галочка «Включено» — правило действует. Снимите, чтобы временно отключить.

ШАГ 5. ТИП ПРАВИЛА (три кнопки)
  Нажмите нужную: «Запрет», «Привязка» или «Лимит». Под кнопками — короткая
  подсказка, что делает выбранный тип. От типа зависит, какие блоки ниже.

ШАГ 6. УСЛОВИЯ
  Условие — это строка «Поле  ->  Оператор  ->  Значение».
  Пример: «День недели  входит в  [Сб]».

  * Кнопка «+ условие» — добавляет ещё одну строку.
  * Если строк больше одной — появляется переключатель:
        «Все условия (И)»  — должны выполняться все строки сразу;
        «Любое из (ИЛИ)»   — достаточно любой одной строки.
  * Крестик справа от строки — удалить эту строку.

  Значение подбирается удобно, в зависимости от поля:
    - Группа / Преподаватель / Дисциплина / Корпус / Аудитория / Тип аудитории
      — выпадающим списком ПО НАЗВАНИЮ (номера-id знать не нужно).
    - День недели — галочками Пн..Вс.
    - Номер пары / Курс / Смена — числом.
    - Дата — календарём.

  Особенности по типам:
    ЗАПРЕТ   — блок «Условия (для каких пар)». Любая пара, подходящая под
               условия, считается нарушением.
    ПРИВЯЗКА — два блока: «Для каких пар» (отбор) и «Обязательно должно
               выполняться» (чему пара обязана соответствовать). Если пара
               попала в отбор, но не выполняет «обязательно» — это нарушение.
    ЛИМИТ    — блок «Считать пары, где» (отбор) + «Группировать по» (галочки
               полей) + «Число пар не больше/не меньше N». Считаются пары в
               каждой группе и сверяются с порогом.

ШАГ 7. РАСШИРЕННЫЙ РЕЖИМ (JSON) — по желанию
  Галочка внизу «Расширенный режим (JSON)». Нужна только для сложной
  вложенной логики (НЕ, И внутри ИЛИ и т.п.). Для обычных правил не трогайте.
  При открытии сложного правила на «Изменить» режим включается сам.

ШАГ 8. СОХРАНИТЬ
  Нажмите «Сохранить». Перед сохранением форма проверит правило и покажет
  ошибку, если что-то заполнено неверно.


------------------------------------------------------------------------------
4. СПРАВОЧНИК ПОЛЕЙ
------------------------------------------------------------------------------

  Группа          — конкретная учебная группа.
  Преподаватель   — преподаватель.
  Аудитория       — конкретная аудитория.
  Корпус          — здание (корпус).
  Тип аудитории   — вид помещения (Аудитория, Лаборатория, Спорт.зал,
                    Спорт.комплекс и т.д.). Удобно для «физра только в зале».
  Дисциплина      — предмет.
  Тип занятия     — код типа (lecture — лекция, practice — практика и т.д.).
  Номер пары      — 1..7.
  День недели     — 1=Пн, 2=Вт, 3=Ср, 4=Чт, 5=Пт, 6=Сб, 7=Вс.
  Дата            — конкретная дата.
  Курс            — номер курса.
  Смена           — 1 или 2.

ОПЕРАТОРЫ:
  =   равно          !=  не равно
  <   меньше         <=  меньше или равно
  >   больше         >=  больше или равно
  входит в (in)      не входит в (not_in)   — для списков (напр. дни недели)


------------------------------------------------------------------------------
5. ГОТОВЫЕ ПРИМЕРЫ
------------------------------------------------------------------------------

ПРИМЕР 1. Группа не учится в субботу.
  Уровень = По группе -> выбрать группу. Тип = Запрет. Строгость = Ошибка.
  Условие: «День недели  входит в  [Сб]».

ПРИМЕР 2. У 1 курса нет пар после 4-й.
  Уровень = По курсу -> 1. Тип = Запрет.
  Условие: «Номер пары  >  4».

ПРИМЕР 3. Преподавателю не больше 4 пар в день.
  Тип = Лимит.
  «Считать пары, где»: «Преподаватель  =  (выбрать)».
  Группировать по: отметить «Преподаватель» и «Дата».
  «Число пар  не больше  4».

ПРИМЕР 4. Дисциплина только в одном корпусе.
  Тип = Привязка.
  «Для каких пар»: «Дисциплина  =  (выбрать)».
  «Обязательно»:   «Корпус  =  (выбрать)».

ПРИМЕР 5. Физкультура — в любом спортивном зале (комплекс ИЛИ зал корпуса).
  Тип = Привязка.
  «Для каких пар»: «Дисциплина  =  Физическая культура».
  «Обязательно» -> переключить на «Любое из (ИЛИ)», добавить две строки:
      «Тип аудитории  =  Спорт.комплекс»
      «Тип аудитории  =  Спорт.зал»


------------------------------------------------------------------------------
6. КАК ЭТО РАБОТАЕТ ВМЕСТЕ С «ПРАВИЛАМИ ГЕНЕРАЦИИ»
------------------------------------------------------------------------------

Авторские правила НЕ конфликтуют со встроенными — они складываются.
Встроенные «Правила генерации» уже отвечают за: окна, один корпус в день,
вместимость аудиторий, минимум пар, недельную нагрузку и т.п.

Авторскими правилами добавляйте то, чего среди встроенных нет: запреты по
дню/паре, лимиты «не больше N», привязки «дисциплина -> корпус/тип зала» и
любую составную логику.

Жёсткие (Ошибка) правила «Запрет» и «Привязка» учитываются прямо при
генерации. Лимиты и мягкие правила проверяются после генерации —
нарушения подсвечиваются в списке конфликтов, их можно поправить вручную.


------------------------------------------------------------------------------
7. ЧАСТЫЕ ВОПРОСЫ
------------------------------------------------------------------------------

В: Правило создано, но ничего не происходит.
О: Проверьте, что включён переключатель «Вкл.», и что уровень/условия
   действительно совпадают с парами (правильная группа, курс, день).

В: Нужно «или то, или это» (несколько вариантов).
О: Добавьте несколько строк-условий и переключите на «Любое из (ИЛИ)».

В: Хочу запретить целиком — без условий.
О: Так нельзя: у «Запрета» должно быть хотя бы одно условие, иначе
   правило запретило бы вообще все пары.
