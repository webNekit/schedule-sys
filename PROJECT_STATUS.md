# Статус проекта: Система управления учебным процессом

## 🚀 Текущие возможности

### 🗓️ Генерация и управление расписанием
*   **Умная генерация:** Учитывает недельную норму часов, последовательность преподавателей (`sort_order`) и специализацию аудиторий.
*   **Поддержка подгрупп:** Автоматическое разделение на подгруппы (Иностранный язык, Информатика) с подбором двух разных преподавателей и аудиторий в один слот.
*   **Мониторинг загрузки (Heatmap):** Обзорная панель на 67 групп для быстрого выявления недобора пар или окон.
*   **Система умных замен:** Быстрый поиск свободного преподавателя на конкретную дату и пару с учетом его нагрузки и дисциплины.
*   **Система индикаторов:** Автоматическое заполнение дней практик (Учебная, Производственная, Преддипломная) и Экзаменационных сессий яркими плашками.
*   **Сменность и графики:** Полная поддержка разных графиков для курсов (например, Пн-Пт для 1-2 курсов и Вт-Сб для 3-4 курсов) через настройки системы.
*   **Правила для Физкультуры:** Автоматическая парность занятий в Спорткомплексе (1-2 или 3-4 пары) и ограничение по времени для обычных залов (до 5 пары).
*   **Контроль конфликтов:** Проверка пересечений по преподавателям, группам и аудиториям. Минимизация перемещений между корпусами.
*   **Публичные ссылки (Day Share):** Генерация ссылок на расписание конкретного дня для всей кафедры с корректным отображением кабинетов и корпусов.

### 📚 Учебные планы и Нагрузка
*   **История по годам:** Группировка учебных планов в виде древовидного аккордеона. Система автоматически переключает актуальный план при смене учебного года.
*   **Календарный график:** Единая таблица всех практик и сессий с возможностью ручного назначения дат экзаменов.
*   **Чистота данных:** Автоматическое скрытие «технических» разделов (ПМ.01, ОД и т.д.) из процесса планирования.
*   **Разделение нагрузки:** Точный учет часов по 1 и 2 полугодиям, а также контроль общего итога за год.

### 👨‍🏫 Преподаватели
*   **Гибкая доступность:** Настройка рабочих часов «по дням» (например, во вторник только 4-5 пары).
*   **Блокировка по практикам:** Если преподаватель ведет **Учебную практику**, система блокирует постановку ему любых других пар на этот период.
*   **Учет вычитки:** Реальное отслеживание проведенных часов (через опубликованные версии расписания) по сравнению с плановыми.

## 🛠️ План доработок (Backlog)

### 1. Логика генерации
*   **Учет подгрупп:** Автоматическое разделение на подгруппы (Иностранный язык, Информатика) с подбором двух разных преподавателей и аудиторий в один слот.
*   **Профили аудиторий:** Валидация типов кабинетов (например, дисциплина «Информатика» должна требовать только аудиторию с типом «Компьютерный класс»).
*   **Методические дни:** Улучшить алгоритм распределения нагрузки, чтобы «выдавливать» пары из методических дней преподавателей более эффективно.

### 2. Учебные планы и Группы
*   **Автоматический перевод:** Кнопка «Перевести на следующий курс», которая сама сдвигает course_number и меняет актуальный учебный год для всей кафедры.
*   **Импорт замен:** Механизм оперативной корректировки расписания при болезни преподавателя (разовые замены без изменения основной версии).
*   **Контрольные точки:** Учет часов консультаций и курсового проектирования в отдельном интерфейсе.

### 3. Отчетность и Аналитика
*   **Журнал вычитки:** Экспорт в Excel ежемесячных отчетов по фактически проведенным часам для бухгалтерии.
*   **Визуализация нагрузки:** Графики «заполненности» преподавателей для выявления тех, у кого слишком много или слишком мало часов.
*   **Уведомления:** Система оповещений в Telegram/Email о начале практик или изменениях в расписании.

### 4. UI/UX
*   **Мобильная версия:** Оптимизация сетки расписания для удобного просмотра со смартфонов студентами и преподавателями.
*   **Drag-and-Drop в расписании:** Возможность перетаскивать уроки прямо в сетке для ручной корректировки конфликтов.
*   **Темная тема:** Финализация стилей для всех модальных окон и таблиц.
